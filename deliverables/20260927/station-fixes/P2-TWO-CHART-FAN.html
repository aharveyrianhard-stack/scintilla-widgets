The RSI fan on the two-chart pages, the SPY/QQQ pages, lookbacks, and Sunday futures

Every Station page that shows two charts now has the six-line RSI fan under both charts. The SPY/QQQ 3-day page and the SPY/QQQ daily page are both on purpose: they come from two separate TradingView layouts of yours. An open Station page already asks for new futures bars every minute, whatever the hour, so when the chart API starts sending Sunday-evening bars they will appear without a reload. No client change was needed for that.

4 · Sunday evening futures: will an open page show the new bars?

Yes, within about six minutes, with no reload and no change needed. What the code does:

  1. Every chart pane re-asks for its series once a minute, whatever the time (chart/index.html:3316). Nothing on that path looks at the NYSE session, the hour or the weekend (scChartLoad, :2696). The deck only limits how many reads run at once (four; deck/index.html:1410). It never holds a read back by the clock.
  2. A series read in the last five minutes is reused (chart/index.html:896), so a new bar lands between 0 and about 6 minutes after the chart API has it. On the rotating wall each page is up for 33 s and comes back about 9½ minutes later at night, so every visit reads fresh.
  3. The ES/NQ quote is read every 10 s (deck/index.html:1961) from the chart API's /macro route (_provider/provider.js:1302). Tonight it answered with a live futures price stamped 21:30 ET. The pane draws that as a temporary last point after the newest finished bar (chart/index.html:706), so the ES/NQ line already moves on a Sunday evening.
  4. A named refusal from the chart API is not retried by the retry timer, but the once-a-minute re-read still asks again. When the server starts answering, the chart comes back by itself (chart/index.html:2759).
Tested headlessly, end to end. INTRADAY · 30M on the real deck, test clock Sunday 21:30 ET. The relay first held back ES's newest four 30-minute bars, then served them all. After the pane's own timers had run for six minutes it had drawn all four new bars (236 → 240, last bar 14:30 → 16:30 ET), with one extra read and no reload. p2-futures-refresh.json, harness/futures-refresh.mjs.

What you will and will not see on Sunday night

  • At night the lap only has the 3-day and daily pages, and a daily or 3-day bar is only drawn once its session has finished. So on those pages Sunday evening shows up as the temporary live point, not as new candles. New Sunday candles show on the intraday pages (INTRADAY · 4H / 1H / 30M), which are in the day lap from 04:00 Monday or can be opened from the menu at any time.
  • The 30M lens on SPY + QQQ · DAY draws regular hours only (09:30–16:00; _indicators/lens-bars.mjs:23), so it never shows Sunday-evening bars. The 4H lens draws 04:00–20:00 (lens-bars.mjs:64), so a Sunday 16:00–20:00 bar would show as a one-candle "Sunday" session. Not changed; futures intraday is on your do-not-change list.

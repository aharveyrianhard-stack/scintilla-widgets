Source & validation

Daily EMA13 / EMA21 and SMA50 / SMA200 form the baseline cloud ribbon. A thin dashed EMA8 adds no cloud; optional dashed SMA100 is a separate level. The Clouds switch is a workshop inspection tool, not a proposal to make clouds optional on Station. These preview averages are computed locally from the fetched daily closes, not read from the database. EMA initialization and exact exchange/session agreement still require TradingView comparison.

One confirmed-daily ribbon is drawn across every price timeframe. Each daily value becomes available at the next supplied session; the latest unconfirmed daily value is excluded. Historical anchors are joined for display, not recalculated or smoothed into new indicator observations. This conservative preview is not a developing-daily TradingView series. Price uses Station's equal-bar spacing and curved trace. No missing bars are filled.

The 10-minute preview pairs complete contiguous five-minute provider bars. Other intraday candles are provider-built. Session coverage is preserved as supplied, including extended hours. Candles and OHLC bars show the same open, high, low and close; candles use a body, bars use left/right ticks.

SAFE MODE · REPLAY DATA

How to inspect with your eyes

  1. Start with the proven 80 ms preset; use 800 ms to make the failure mode obvious.
  2. Fix your gaze on the same avatar or card edge across all three panes: reference glides, raw holds and jumps, interpolated glides one delivery behind.
  3. Watch RAW GAP and INTERP GAP together. Interpolation should remove the hold/jump without inventing a different delivered endpoint.
  4. Let the fixed run finish. Judge the result from maximum gaps, endpoint error, and the final checklist—not from one convenient moment.

LAB VISUAL TARGET: ≤ 6 PX for raw and interpolated maximum motion gap, plus ≤ 0.01 px endpoint error. This is a synthetic viewing heuristic, not production acceptance.

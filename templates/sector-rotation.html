Current authority contract: Massive provider APIs own equity prices, completed bars and Geiger. Raw FMP provider_indicators_current owns the daily RSI/Williams/EMA/SMA values. There is no Yahoo or locally computed fallback. Missing provider data stays visibly unavailable.

FORMULAS & COMPUTATIONS — what feeds what
This section is ordered as dependency chains: raw input → each derived step → what is displayed.

Chain 1 — Relative Performance %: completed provider daily/intraday closes → (close_i / close_base − 1) × 100, base = first visible bar → % lines. Glow width uses static AUM only as display geometry; it does not change values.
Chain 2a — RRG: completed provider weekly closes → RS = 100 × sector/SPY → EMA(4) → 14-week z-scored RS-Ratio and 4-week RS-Momentum → EMA(2) → quadrant and tail. No alternate bar source.
  Quadrant series, walked backward → Weeks In + "just crossed" flag (weeks==1) → Regime Read "just crossed" list, labeled lagging/confirmatory (can only fire after a rotation change already happened).
  RS-Ratio, grouped Cyclicals vs Defensives → averaged per group → spread → RISK-ON/RISK-OFF/MIXED badge (±0.6 threshold) + breadth counts → "What this means" rules block. This is the one current sector-regime result on the page; the stale internal regime_state output is retired from the surface, not blended with it.
Chain 2c — Extension Watch: raw FMP RSI(14) + Williams %R(14) + provider price versus raw FMP SMA50. Missing any required provider input makes the read unavailable.
Chain 3 — Technicals scorecard / Sector Sentiment / Actionable Read: raw FMP RSI/Williams/EMA21/SMA50 plus Massive provider price → visible pass/fail rules. MACD/CCI/ROC/Stochastic are not counted because no accepted provider value is loaded. No browser-computed fallback exists.
Chain 4 — Geiger: accepted /geiger output only. If it cannot be read, the Geiger tab says unavailable and does not calculate an older approximation.
Chain 5 — AUM sizing (③, static): AUM $B map → RRG head/tail radius (√AUM), heatmap tile size (squarified treemap), Quadrant table's AUM column, Relative Performance Glow-mode taper width, and the standalone Fund Size panel's 4 display views — no different data underneath, purely a display choice.
Chain 6 — Sub-Industry / Top Holdings (③, static, BLOCKED from moving to ①): ETF_DETAIL hand-compiled list + TOP_HOLD_PCT illustrative decay curve → shown as-is, not derived from anything else, not live. Supabase etf_holdings/etf_info are the ordered replacement but both are confirmed EMPTY (0 rows) for our 12 tickers — logged as an outstanding blocker, not silently worked around.
Outstanding: holdings/fundamentals remain static or explicitly pending. MACD/CCI/ROC/Stochastic remain unavailable until accepted provider values are loaded. These gaps do not activate a fallback.

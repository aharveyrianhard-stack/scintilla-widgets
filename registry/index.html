0 · How on/off works

Pull out: a piece is extracted when it has its own live URL below — windowable, scene-composable, same data, DB reads only. See it alone: open the URL. Put it back: free, always — extraction never modifies the cockpit; its inline copy never left. The one thing that would need a cockpit deploy is on/off toggles inside the cockpit's own frame — queued, your ruling, nothing waits on it.

PHONE column: safe = no nested pages, opens clean. tap-to-load = light by default, panes load only when you tap and are capped. wall-only = built for the 1920×1080 wall; it opens multiple nested documents and will strain a phone.

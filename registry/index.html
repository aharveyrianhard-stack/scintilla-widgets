0 · How on/off works

Pull out: a piece is extracted when it has its own live URL below — windowable, scene-composable, same data, DB reads only. See it alone: open the URL. Put it back: free, always — extraction never modifies the cockpit; its inline copy never left. The one thing that would need a cockpit deploy is on/off toggles inside the cockpit's own frame; that single unlock is yours to rule on, and no extraction below waits on it.
